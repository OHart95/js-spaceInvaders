# 🚀 Space Invaders (Vanilla JavaScript)

A **work‑in‑progress** implementation of a classic *Space Invaders* style game built using **vanilla JavaScript**, HTML, and CSS.

This project focuses on core game development concepts without relying on external frameworks or libraries.

---

## 🧪 Project Status

🚧 **Work in Progress**

This project is actively being developed and refactored. Features, structure, and gameplay mechanics are subject to change.

---

## 🎮 Overview

The goal of this project is to recreate the core mechanics of the classic *Space Invaders* arcade game using plain JavaScript, with an emphasis on:

* Game loops and animation
* Keyboard input handling
* Collision detection
* Managing game state
* DOM or canvas‑based rendering

The project serves as both a learning exercise and a foundation for future enhancements.

---

## ✨ Current Features

* Player movement and shooting
* Enemy (invader) movement
* Basic collision detection

*(Feature list will evolve as development continues.)*

---

## 🛠️ Built With

* **JavaScript (ES6+)**
* **HTML5**
* **CSS3**
* No external libraries or frameworks

---

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/space-invaders.git
cd space-invaders
```

### Run the Game

This project does not require a build step.

Simply open the `index.html` file in your browser, or use a local server:

```bash
npx serve
```
